## REQ-001: 撮影画像から牌を検出する 🔵

**信頼性**: 🔵 *PRD「画像認識機能」+ ユーザヒアリング「8-9枚」「ブラウザ内」より*

### Given（前提条件）
- カメラで手牌（8-9枚）の写真が撮影されている
- 牌画像データ（84種類）がアプリに組み込まれている

### When（実行条件）
- 撮影完了後、認識処理が開始される

### Then（期待結果）
- 画像内の牌の位置が検出される
- 検出された牌の数が表示される

### テストケース

#### 正常系

- [ ] **TC-001-01**: 8枚の手牌が写った画像から8枚すべてを検出する 🔵
  - **入力**: 8枚の牌が並んだ撮影画像
  - **期待結果**: 8枚の牌が検出される
  - **信頼性**: 🔵 *ユーザヒアリング「8-9枚」より*

- [ ] **TC-001-02**: 9枚の手牌が写った画像から9枚すべてを検出する 🔵
  - **入力**: 9枚の牌が並んだ撮影画像
  - **期待結果**: 9枚の牌が検出される
  - **信頼性**: 🔵 *ユーザヒアリング「8-9枚」より*

#### 異常系

- [ ] **TC-001-E01**: 牌が写っていない画像で検出結果が0件 🟡
  - **入力**: 牌が含まれない撮影画像
  - **期待結果**: 「牌が検出されませんでした」のメッセージ表示
  - **信頼性**: 🟡 *一般的なUXから妥当な推測*

- [ ] **TC-001-E02**: 暗すぎる画像での認識 🟡
  - **入力**: 暗い環境で撮影された画像
  - **期待結果**: 検出できた牌のみ結果表示、または検出不可のメッセージ
  - **信頼性**: 🟡 *実使用シーンから妥当な推測*

#### 境界値

- [ ] **TC-001-B01**: 1枚だけの牌を検出する 🟡
  - **入力**: 1枚の牌のみの撮影画像
  - **期待結果**: 1枚の牌が検出される
  - **信頼性**: 🟡 *境界条件として妥当な推測*

## REQ-002: 検出した牌を84種類から識別する 🔵

**信頼性**: 🔵 *PRD + tiles.json（84種の牌データ）より*

### Given（前提条件）
- 画像から牌が検出されている
- 84種類の牌データ（画像 + tiles.json）が利用可能

### When（実行条件）
- 検出された各牌に対して識別処理が実行される

### Then（期待結果）
- 各牌が84種類のいずれかに分類される
- 各牌に日本語名が紐づけられる

### テストケース

#### 正常系

- [ ] **TC-002-01**: μ'sグループの牌を正しく識別する 🔵
  - **入力**: μ'sキャラクター（例: 高坂穂乃果）の牌画像
  - **期待結果**: 「003_muse_honoka.png」/「高坂穂乃果」として識別
  - **信頼性**: 🔵 *tiles.jsonのデータ構造より*

- [ ] **TC-002-02**: エンブレム牌を正しく識別する 🔵
  - **入力**: グループエンブレム（例: μ'sエンブレム）の牌画像
  - **期待結果**: 「001_muse_muse.png」/「μ's」として識別
  - **信頼性**: 🔵 *tiles.jsonのデータ構造より*

- [ ] **TC-002-03**: 異なるグループの牌を区別する 🔵
  - **入力**: 複数グループの牌が混在する手牌
  - **期待結果**: 各牌が正しいグループ・キャラクターとして識別
  - **信頼性**: 🔵 *84種の牌画像が識別対象として確定*

#### 異常系

- [ ] **TC-002-E01**: 牌以外のオブジェクトの処理 🟡
  - **入力**: 牌に似た別のオブジェクト
  - **期待結果**: 識別不能または最も類似する牌として表示
  - **信頼性**: 🟡 *一般的な画像認識の課題から推測*

## REQ-004: 手牌から加点役を判定する 🔵

**信頼性**: 🔵 *PRD「役を確認」+ ユーザヒアリング「Must Have」より*

### Given（前提条件）
- 手牌の認識が完了している
- 加点役のルールデータ（JSON）が読み込まれている

### When（実行条件）
- 認識された手牌の組み合わせで加点役を判定する

### Then（期待結果）
- 該当する加点役が一覧表示される
- 加点役がない場合はその旨が表示される

### テストケース

#### 正常系

- [ ] **TC-004-01**: 加点役に該当する手牌で役が判定される 🟡
  - **入力**: 加点役の条件を満たす手牌の組み合わせ
  - **期待結果**: 該当する加点役名が表示される
  - **信頼性**: 🟡 *具体的なルールはmanual.pdfの解読が必要*

- [ ] **TC-004-02**: 複数の加点役が同時に成立する場合 🟡
  - **入力**: 複数の加点役条件を満たす手牌
  - **期待結果**: すべての該当加点役が一覧表示される
  - **信頼性**: 🟡 *麻雀の一般的なルールから推測*

#### 異常系

- [ ] **TC-004-E01**: 加点役に該当しない手牌 🟡
  - **入力**: いずれの加点役条件も満たさない手牌
  - **期待結果**: 「加点役なし」と表示される
  - **信頼性**: 🟡 *一般的なゲームUIから妥当な推測*

## REQ-005: 加点役に基づいてジャラを計算する 🔵

**信頼性**: 🔵 *PRD「点数を確認」+ ユーザヒアリング「Must Have」より*

### Given（前提条件）
- 加点役の判定が完了している
- ジャラ計算のルールデータ（JSON）が読み込まれている

### When（実行条件）
- 判定された加点役に基づいてジャラを計算する

### Then（期待結果）
- 合計ジャラが表示される
- 各加点役ごとのジャラ内訳が表示される

### テストケース

#### 正常系

- [ ] **TC-005-01**: 単一の加点役のジャラ計算 🟡
  - **入力**: 1つの加点役が成立した手牌
  - **期待結果**: その加点役に対応するジャラが表示される
  - **信頼性**: 🟡 *具体的な点数はmanual.pdfの解読が必要*

- [ ] **TC-005-02**: 複数加点役の合計ジャラ計算 🟡
  - **入力**: 複数の加点役が成立した手牌
  - **期待結果**: 各加点役のジャラ + 合計ジャラが表示される
  - **信頼性**: 🟡 *麻雀の一般的な得点計算から推測*

#### 異常系

- [ ] **TC-005-E01**: 加点役なしの場合のジャラ 🟡
  - **入力**: 加点役が成立しない手牌
  - **期待結果**: ジャラ: 0（または基本点のみ）と表示される

## REQ-007: 画像認識をブラウザ内で実行する 🔵

**信頼性**: 🔵 *ユーザヒアリング「ブラウザ内（クライアント側）」より*

### Given（前提条件）
- アプリがスマホブラウザで開かれている
- ネットワーク接続の有無を問わない

### When（実行条件）
- 画像認識処理が実行される

### Then（期待結果）
- すべての処理がブラウザ内で完結する
- 外部サーバーへの通信が発生しない

### テストケース

#### 正常系

- [ ] **TC-007-01**: オフライン環境でも認識が動作する 🔵
  - **入力**: ネットワーク切断状態で撮影・認識
  - **期待結果**: 正常に認識結果が表示される
  - **信頼性**: 🔵 *SPA + クライアントサイド処理の帰結*

- [ ] **TC-007-02**: 外部への通信が発生しない 🔵
  - **入力**: 認識処理の実行
  - **期待結果**: ネットワークタブに外部リクエストが記録されない
  - **信頼性**: 🔵 *REQ-401の帰結*
