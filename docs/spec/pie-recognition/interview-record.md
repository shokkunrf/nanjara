# パイ認識アプリ ヒアリング記録

**作成日**: 2026-03-12
**ヒアリング実施**: step4 既存情報ベースの差分ヒアリング

## ヒアリング目的

既存のPRD（docs/aa.md）、牌画像データ（tools/extractor/output/）、既存実装（カメラ撮影機能）を確認し、画像認識・加点役判定・結果表示に関する不明点を明確化するためのヒアリングを実施しました。

## 質問と回答

### Q5: ユビキタス言語の定義

**質問日時**: 2026-03-12
**カテゴリ**: 未定義部分詳細化
**背景**: PRDで「ユビキタス言語を決めたい」と明記されていた

## ヒアリング結果サマリー

### 確認できた事項
- 画像認識はブラウザ内（クライアントサイド）で実行
- 手牌は8-9枚（このゲーム固有のルール）
- manual.pdfが正式ルール、JSONで管理
- 認識結果は一覧リスト表示
- ユビキタス言語: パイ=牌、加点役=役、ジャラ=点数
- 撮影から結果表示まで3秒以内
- スマホ（iOS/Android）のみ対応
- ゲーム中の確認用途
- 牌の画像認識・結果表示・加点役判定はすべてMust Have
- ルールデータはapp/staticに配置

### 追加/変更要件
- ユビキタス言語の正式定義（「グループ」は「加点役」に内包）
- ルールデータのJSON管理・配置場所の確定
- 速度要件（3秒以内）の具体化
- 手動修正機能は後回し（オプション要件へ）

### 残課題
- manual.pdfの具体的なルール内容の解読（PDF読み取り環境が必要）
- 画像認識の具体的なアルゴリズム選定（設計フェーズで検討）
- 牌画像の事前処理方法の詳細（設計フェーズで検討）
- 加点役・ジャラのJSONスキーマ設計（設計フェーズで検討）

- 🟡 黄信号: 6件
- 🔴 赤信号: 12件

**ヒアリング後**:

- 🟡 黄信号: 8件 (+2)
