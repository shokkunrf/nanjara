## 概要

app/src/lib/services/phash.ts を実装。ブラウザ環境でImageDataからpHashを計算し、ハミング距離を比較する純粋な計算モジュール。

## 実装詳細

- phash.ts 作成 🔵
  - computePHash(imageData: ImageData): string — ImageDataからpHash計算
    - グレースケール変換 → 8x8リサイズ → DCT → 中央値比較 → 64bitハッシュ
  - hammingDistance(hash1: string, hash2: string): number — ハミング距離計算
  - findClosestMatch(hash: string, hashMap: PaiHashMap): { paiId: PaiId, distance: number } — 最近傍マッチング
- Canvas APIでリサイズ処理 🟡
