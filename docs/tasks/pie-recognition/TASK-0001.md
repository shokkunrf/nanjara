## 概要

tools/hasher/ にNode.jsツールを作成。tools/extractor/output/ の84枚PNG画像を読み込み、各画像のpHashを計算して app/static/pais/hashes.json に出力する。

## 実装詳細

- tools/hasher/package.json 作成（TypeScript, sharp or canvas等の画像処理ライブラリ）🔵
- tools/hasher/src/main.ts 作成 🔵
  - 画像読み込み → グレースケール変換 → 8x8リサイズ → DCT → 中央値比較 → 64bitハッシュ生成
  - 84枚すべてのpHashを計算
  - { "001_muse_muse.png": "a1b2c3...", ... } 形式でhashes.jsonに出力
- tools/hasher/tsconfig.json 作成 🔵
