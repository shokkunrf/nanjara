## 概要

app/src/lib/services/pai-detector.ts を実装。IPaiDetector インターフェースに従い、撮影画像からOpenCV.jsのfindContoursでパイ領域を検出する。

## 実装詳細

- pai-detector.ts 作成 🟡
  - detect(imageSource): Promise<DetectedRegion[]>
    1. 画像を検出用サイズに縮小 🟡
    2. cv.cvtColor（グレースケール変換）🔵
    3. cv.threshold（2値化・大津の方法）🔵
    4. cv.findContours（輪郭検出）🔵
    5. cv.boundingRect（バウンディングボックス抽出）🔵
    6. アスペクト比・面積フィルタ 🟡
    7. 左から右の順にソート 🟡
    8. Mat オブジェクト解放（try-finally）🔵
