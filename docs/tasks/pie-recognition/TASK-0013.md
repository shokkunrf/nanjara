## 概要

CameraResult.svelte に「認識する」ボタンを追加。ボタンタップで認識処理を開始し、プレビュー画面表示時にOpenCV.jsの先読みロードを開始する。認識結果は /result に遷移して表示。

## 実装詳細

- CameraResult.svelte 拡張 🔵
  - 「認識する」ボタンを追加 🔵
  - プレビュー表示時に opencvLoader.preload() 呼び出し 🔵
  - ボタンタップ時の処理フロー:
    1. ローディング表示 🟡
    2. opencvLoader.ensureLoaded() 🔵
    3. paiDetector.detect(imageSource) 🔵
    4. paiRecognizer.recognize(regions) 🔵
    5. /result に遷移（認識結果データを渡す）🔵
  - エラー時の表示（パイ未検出等）🟡
