## 概要

app/src/lib/services/scoring-engine.ts を実装。IScoringEngine インターフェースに従い、手牌のパイIDから属性を参照し、加点役を判定してジャラを計算する。

## 実装詳細

- scoring-engine.ts 作成 🔵
  - score(paiIds: PaiId[]): ScoringResult
    1. pais.json から各パイの属性データを取得（初回のみ、以降キャッシュ）🔵
    2. rules.json から加点役定義を取得（初回のみ、以降キャッシュ）🔵
    3. 各加点役の条件を評価 🔵
      - same_attribute: 手牌内で同じ属性値を持つパイが一定枚数以上
      - attribute_value: 特定属性が特定値のパイが存在
    4. 該当する加点役を抽出 🔵
    5. 各加点役の固定ジャラを単純合算 🔵
    6. ScoringResult を返す 🔵
