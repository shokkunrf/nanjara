## パフォーマンスレビュー結果

### 改善前の問題

`dct1d` 関数が N=32 固定で 64回呼ばれる際、`Math.cos()` を毎回計算しており:
- 合計呼び出し数: 64回（dct2d）× 32（k）× 32（n）= **65,536回** の `Math.cos()`

### 改善後

`DCT_COS_TABLE` をモジュール初期化時に1度だけ計算:
- 事前計算: 32 × 32 = **1,024回** のみ（テーブル生成時に1度だけ）
- 実行時: テーブル参照（乗算・加算のみ）

### テスト実行時間

テスト21件の実行時間: **30ms**（2秒以内、問題なし）

## 改善内容一覧

### 改善1: DCT cos値ルックアップテーブル化 🟡

**変更箇所**: `phash.ts` に `DCT_COS_TABLE` 定数を追加、`dct1d` を修正

**改善前**:
```typescript
function dct1d(input: number[]): number[] {
  for (let k = 0; k < N; k++) {
    for (let n = 0; n < N; n++) {
      sum += input[n] * Math.cos((Math.PI * (2 * n + 1) * k) / (2 * N));
    }
  }
}
```

**改善後**:
```typescript
// モジュール初期化時に一度だけ計算
const DCT_COS_TABLE: number[][] = (() => { /* ... */ })();

function dct1d(input: number[]): number[] {
  for (let k = 0; k < N; k++) {
    const cosRow = DCT_COS_TABLE[k]; // テーブル参照
    for (let n = 0; n < N; n++) {
      sum += input[n] * cosRow[n]; // Math.cos() 不要
    }
  }
}
```

**効果**: Math.cos() の実行時呼び出しをゼロに削減

### 改善2: ビット列文字列の中間生成を排除 🟡

**変更箇所**: `computePhash` のハッシュ生成部分

**改善前**: 64文字のビット列文字列を生成してから4文字ずつ16進数に変換
**改善後**: ニブル単位（4ビット）で直接16進数文字を生成

**効果**: 中間的な64文字の文字列オブジェクトの生成を排除、メモリ効率向上

### 改善3: `dct2d` のJSDoc注釈強化 🔵

**変更箇所**: `dct2d` 関数のコメント

**改善内容**: `DCT_COS_TABLE` に依存して `size=32` でのみ正しく動作するという制約を明記
